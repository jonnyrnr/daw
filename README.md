GridSound is a free, work-in-progress, half open-source digital audio workstation written with HTML5 and more precisely with the WebAudio API.

## ✨ Latest Features (v0.42.0)

### 🎤 Sensor MIDI Triggering System
Now you can control GridSound using biometric and device sensors:

- **Body Tracking** - Full body pose detection via camera
- **Heart Rate** - Bluetooth heart rate monitor support
- **Gestures** - Hand gesture recognition (thumbs up, pinch, open palm, etc.)
- **Accelerometer** - Device motion detection
- **Gyroscope** - Device rotation and tilt control
- **Touch** - Multi-touch screen MIDI mapping

All sensors auto-detect on startup and map to MIDI for intuitive musical control.

**Documentation:** See [Sensor MIDI Guide](docs/SENSOR_MIDI_GUIDE.md) and [Integration Guide](docs/SENSOR_MIDI_INTEGRATION.md)
